**The system is complete for the pilot scope, with a short list of open decisions and checks.** Gaps fall into three groups: features the project chose not to build, production checks, and code items found during this documentation work.

## 3. Code items found during documentation

| Item | Impact | Suggested action |
| --- | --- | --- |
| Two entity classes map the same `notifications` table | Confusing. Risk of drift between the two definitions. | Confirm and remove the unused one |
| BullMQ job `failedReason` shows stale text in some job status responses | Cosmetic only | Fix when the queue views are next changed |
| Document preview uses a plain image tag | Accepted decision | Revisit if a document-preview policy is set |
| Frontend notification bell opens a dropdown. The admin bell is a plain link. | Inconsistent behaviour | Decide the standard, then align the other app |
| Old specs in `nsgdp-backend/docs/` describe the design, not the build | Misleading for new readers | See [Old documents](/old-docs) |
